# Baqylau — фирменная палитра (для презентации и слайдов)

Стиль: **Soft Bento Grid** — мягкие пастельные карточки, скругления 18–22px,
тёмный текст `#1A1A1A`, шрифт Segoe UI / Inter.

## База

| Токен      | HEX       | Где используется                              |
|------------|-----------|-----------------------------------------------|
| Фон        | `#F4F6F0` | фон приложения и сайта                        |
| Текст      | `#1A1A1A` | весь текст                                    |
| Серый текст| `#6B6B6B` | подписи, время                                 |
| Карточка   | `#FFFFFF` | controls, шапка, отчёты (рамка `#E8E8E8`)     |
| Тёмная     | `#1E1E1E` | карточка камеры (текст на ней `#FFFFFF`)      |

## Акценты (карточки)

| Токен   | HEX       | Смысл                                        |
|---------|-----------|----------------------------------------------|
| Зелёная | `#D4F5A6` | статус ОК, старт экзамена, Pass              |
| Фиолет  | `#D8D4FF` | EEG/внимание, формы, пользователи            |
| Жёлтая  | `#FFF4A3` | нарушения-лента, ученики, калибровка         |
| Розовая | `#FFD4EC` | уведомления/критичное                        |
| Красная | `#FFC1C1` | завершить/удалить, HIGH                      |

## Шкала риска (пилюли + бары)

| Уровень  | Цвет        |
|----------|-------------|
| OK       | `#2E7D32` (зелёный) |
| LOW      | `#E8F5E9` фон |
| MEDIUM   | `#EF6C00` / фон `#FFE0B2` |
| HIGH     | `#C62828` / фон `#FFCDD2` |
| CRITICAL | `#7B0000`, белый текст |

## Веб-панель (токены макета)

Фон `#F3F6EE`, линия `#E3E8DA`, текст `#141414`, лайм `#D4F5A5`, сирень
`#DAD3FD`, жёлтый `#FEF3A6`, розовый `#FFD6EB`; шрифт Inter с системным
фолбэком. Шкала карточек: low `#2F7D32`, med `#D9822B`, high `#D23B3B`.

## Для слайдов Demo Day

- Заголовки: 28–32px, weight 800, `#1A1A1A` на `#F4F6F0`.
- Карточки смыслов цветами выше: зелёная «Старт», жёлтая «Нарушения», красная «Доказательства».
- Логотип-заглушка: 🍈 + **Baqylau** (Segoue UI Black).

## Где лежат записи

| Что | Где |
|-----|-----|
| Фото/видео-доказательства (ПК ученика) | `baqylau/data/logs/snapshots/` — `EVIDENCE_*.jpg/.mp4`, `CRITICAL_*.jpg` |
| Локальные события ученика | `baqylau/data/logs/events.jsonl` (+ `.csv`) |
| Загруженное на сервер (ПК препода) | `baqylau/data/evidence/` — открывается из «Уведомлений» и «Аудита» |
| База сервера (пользователи, оценки, события) | `baqylau/data/baqylau.db` (SQLite) |
| Облако (опционально) | Google Drive, если заданы `BAQYLAU_DRIVE_FOLDER_ID` + credentials; ссылка видна в «Аудите» (☁️), иначе 💾 локально |
